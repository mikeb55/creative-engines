## What the page does

`#/practice` still lists the Scale Explorer. Choosing a mask lights that collection on the existing `FretboardPanel`. Changing the mask, the root, the tuning, the label mode, the fret window, or the position filter rebuilds the dots immediately.

The root rotates the selected pitch classes. A set that contains pitch class 0 is written from C, so root G adds 7 to every class. A set that does not contain 0 rotates around its lowest class. Intervals from the new root match the intervals from that origin. Spelling uses `PENTATONIC_NOTE_CHOICES`.

Green dots are the root pitch class (`triadRoot` on the existing panel). Amber dots are the other members (`primaryTension`). Both colours are markers. They are not scale degrees, chord tones, or fingerings.

## Tunings

The tuning menu lists every catalogued preset except `custom`.

That includes:

- `standard`
- the 24 `ROADMAP_ZONE_TUNING_PRESET_IDS`
- the other catalogued ids already stored beside them (`open_g`, `drop_d`, `dadgad`, `open_d`, `eb_standard`, and the rest)

Open strings are the preset’s scientific names. MIDI is `openStringMidisForTuning`, which parses those names. Standard open MIDI is `40 45 50 55 59 64`, the same low-to-high order as `GUITAR_OPEN_STRING_MIDIS` and the reverse of `pcFretboard` `OPEN_STRINGS`.

An unknown id falls back to standard and the page says so. `custom` has no stored pitches, so it also stays on standard and says fingering is not solved. `pcFretboard` is not called for either case, and it is not called for any non-standard preset.

Dot positions are `open MIDI + fret`. A Drop D or DADGAD shape is not a standard-tuning fingering moved onto those strings.

## Controls and clicks

| Control | Behaviour |
| --- | --- |
| Explorer row | Replaces the pitch-class set |
| Root | Rotates the set. Pitch-class intervals from the root stay put |
| Tuning | Switches open MIDI. Disables the position filter off standard tuning |
| Dot labels | Pitch names, or semitone intervals from the root (`R` for the root) |
| Fret from / fret to | Whole frets from 0 through 24. Dots outside the window are omitted. A reversed range shows no dots and a limitation |
| Position filter | Standard tuning only. Position 0 is open strings. Position N shows frets N through min(N+4, 15) |

The neck still draws from the nut through fret `to`. `positionLock` stays on so the board does not crop itself to the dots.

A click reports string index (0 is the lowest open string) and fret. The readout gives sounding spelling, MIDI, pitch class, interval from the root, whether the pitch is in the selected set, whether it is inside the fret window, and whether it sits in `guitarRange()`.

## Locations, positions, fingerings

Three different facts stay labelled apart:

1. **Pitch-class location.** Any fret whose sounding pitch class is in the transposed set. This is what the dots are.
2. **Possible position.** On standard tuning, a fretted fret can sit in a `pcFretboard` window whose lowest fretted fret is P and whose top is at most P+4, capped at fret 15. The readout lists those position numbers with `romanPosition`. Open strings and frets above 15 have none.
3. **Verified pitch location.** On standard tuning, at fret 15 or below, and inside `guitarRange()`, `fingeringOptions` is asked about that one MIDI pitch. If one option is this string and this fret, the readout says so. That is one place for one pitch. It is not a scale fingering and not a chord grip.

A position window that holds more than four pitches says fingering is not solved, because `fingeringOptions` stops at four sounding pitches. The window is still only a filter.

Frets 16–24 can show pitch-class locations. They are outside the solver. The page says that instead of inventing a fingering.

Locations outside `guitarRange()` stay visible and are marked as not playable notes.

## Limitations

- No practice generator, metronome, session file, or TAB.
- No note or scale playback until V3.2-E.
- No CAGED, three-note-per-string, or named box system.
- `pcFretboard` does not take open-string MIDI. Alternate tunings are locations only.
- A verified result is one pitch on one string. The scale itself is not fingered.
- The visible neck starts at the nut even when “Fret from” is above 0.
- Dot spelling follows `PENTATONIC_NOTE_CHOICES` (F#, Bb, Eb). Preset open-string names keep the catalog spelling.
- `custom` is not a free string editor.
