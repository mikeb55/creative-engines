## What V1.0 still describes correctly

- BHL writes guitar against a locked upright bass.
- Six worlds, A–F. World B is the liquid-harmony world. There is still no button named Liquid Harmony for that world.
- Pentatonic colour, twenty collections, path and phrase on the Pentatonic page.
- Without a hexatonic colour, three candidates stay Candidate 1–3.
- Save, reopen, MusicXML export, MuseScore 4.
- Candidates are for audition. They are not approved.
- The 15 October 2026 Quick Start says the desktop build dated 13 October 2026 does not contain the BHL page. That warning still matters until a new desktop build is authorised and checked.
