## 5. Generator fingerprint preservation

With `motifOps` omitted or `enabled` not strictly true, `buildThemeGenome` does not call the shared operators. F15 matches the hash taken on this tree with the flag off: `c85f0e77…de3aa`. The final smoke’s existing golden rows stayed in the pass count (unexpected fail 0). That is the generator-output check. F15 is a theme-genome JSON hash, not a stored MusicXML dump of every preset from `8a50369b`.

`roleOf` now classifies cello as cello. That changes analysis labels. It does not rewrite generator notes.

## 6. Deliberate differences between existing and shared transformations

From `motif-ops/adapters.ts`. Generators were not rewritten onto the shared library.

- Pentatonic rotation cycles one note forward. Shared retrograde reverses pitches and durations.
- Pentatonic transposition moves one step of that collection. Shared in-field transposition takes an explicit degree count.
- M-DEG and M-NEAR map between pentatonic collections. Shared in-field inversion reflects degrees inside one field.
- BHL continuation strategies label phrase regions. Shared fragment and sequence operators rewrite one cell and record a step.
- BHL invert-into-field is a region reason. It does not call shared degree inversion.
- Berg retrograde reverses a twelve-tone row. Shared retrograde reverses a rhythmic cell, including rests.
- Motif budget flags stay on the cell. They run only when `motifOps.enabled` is true.

`sectionRecallEnforcer` was left on its own sequence path.

## 7. Motif-discovery performance

A 4000-event part finished in **33 ms**, returned **20** patterns, and set `truncated: true` because the part is over the 64-event window cap. The smoke row also asserts under 2 seconds and at most 20 patterns.

Discovery scans contiguous slices of length 3–12. It does not enumerate every subset. `truncated` means the window cap was exceeded.

## 8. Known limitations and deferred work

Spec deferrals D1–D8 stay deferred: no IDyOM, no automatic dissonance or parallel repair, no new theory engine.

Also:

- `insert-rest` can warn `rest at onset 0` even when the rest is later.
- Unrelated-triad default roots are C, Eb, F# when the caller passes no list.
- Hook identity uses interval shape. Absolute MIDI identity assumes the discovered cell sits on MIDI 60.
- BHL import still needs a file on disk. The studio downloads MusicXML and shows an import banner.
- Desktop IPC handlers are in source. The desktop app was not rebuilt.
- `#/develop` and the Coherence tab were not opened in a browser.
