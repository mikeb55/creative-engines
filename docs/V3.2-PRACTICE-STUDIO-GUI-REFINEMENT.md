## What the page does

1. The page opens on **A Dorian** (mask 1709, root pitch class 9).
2. One root and one scale drive the fretboard, Play Scale, exercises, export, save, and the BHL handoff.
3. **Play Scale** builds one octave up and back as eighth notes and sends that MusicXML to the existing `ScoreAudition` player. No drone. The player is one line.
4. Browsing is Essentials, Composer OS Collections, More Named Scales, All Scales, and Advanced Set Theory.
5. The list and the heading show the musical name and the interval formula. Set theory is the view that shows the mask and the Forte number in the list.
6. Forte, Rahn, Zeitler, modes, and the Ian Ring link sit in **About this scale**. The panel starts closed. The Ian Ring id is the mask. A Dorian links to `https://ianring.com/musictheory/scales/1709`. Hirajoshi links to `https://ianring.com/musictheory/scales/397`.
7. Root notes stay filled circles. Scale tones are squares. The legend reads “Root: filled circle.” and “Scale tone: square.”
8. The default view does not show `guitarRange()`. The sentence on the page is “Inside the playable guitar range.”
9. Exercise family and difficulty stay visible. Bars, metre, tempo, and seed stay inside More exercise controls.
10. **Develop in BHL Composer** appears only when a scalar, WPS, provisional, or advanced colour resolves to the same sounding set as the fretboard. **Use in Generate** is not on the page. Generate imports chord-symbol MusicXML. It has no scale handoff.

An inbound collection selects the registered scale and sets the root. D major pentatonic stays named. The heading is “D Major Pentatonic”, and the sounding set is `2,4,6,9,11`.
