# V3.2 — Master scale glossary

**Date:** 2026-10-16

## What landed

The Scale Explorer still has one row per mask, `0` through `4095`.

Each row now has a computed identity in `math`:

| Field | Rule |
| --- | --- |
| Ian Ring id | Equal to the mask. Link only when bit 0 is set |
| `rootMsbNumber` | 12-bit reversal. Zeitler and Tonal chroma use this order |
| Steps | Semitone gaps, tonic-fixed sets only, including the wrap to the octave |
| Modes | Each member transposed to pitch class 0. Not the same operation as `T1` |
| Transposition class | Lowest mask among the 12 transpositions |
| Rahn prime | Lowest mask among transpositions and inversions |
| Forte prime | Left-packed normal form, the same rule as `primeForm` |
| Forte number | Lookup of that prime in `forte-table.json` |
| Zeitler maximum step | Tonic-fixed and no step larger than 4 |

The existing `forte` field is still the hexachord catalogue label, with its status string. Other cardinalities leave it null and do not call `classifyPitchClassSet`.

## Names

`named-scales.json` has 85 rows from Tonal.js `@tonaljs/scale-type` 4.9.4, retrieved 2026-10-16. The research note estimated about 92. The fetched file has 85. Masks were built from interval spellings. Tonal chroma integers were not used.

Composer OS pentatonic and hexatonic registrations are unchanged. A glossary row has `status: null`. Provisional and advanced statuses stay on their own registrations.

No Ian Ring, Zeitler, or Pecot name list was imported. Disputed dictionary usage is kept as text on the Tonal `diminished` row (whole-half, mask 2925). Half-whole, mask 1755, is not given that name.

## Checks against the research fixtures

Independent computation matched the fixture file:

- 4,096 masks, 2,048 tonic-fixed, 1,490 with maximum step 4, and the per-cardinality counts
- 352 transposition classes and 224 TnI classes, empty set included
- The six Rahn/Forte prime pairs in the fixture, and no seventh pair
- Mode list and `T1` for mask 2741
- Mask 1257 is computed Forte `6-Z47` inversion B. The hexachord catalogue string remains `6-47`

music21 8.3.0, not 10.5.0, was the local checker. Prime form and A/B inversion agreed with music21 8.3 on all 4,096 masks. music21 8.3 writes `6-47B` and reports Z separately. The glossary stores `6-Z47` plus `inversion: 'B'`, which is the research schema. music21 8.3 calls the empty set `N/A`. The table uses `0-1`.
