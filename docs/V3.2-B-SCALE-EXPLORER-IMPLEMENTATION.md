## Mask enumeration

A pitch-class subset is an integer mask from 0 through 4095. Bit *n* set means pitch class *n* is present. Bit 0 is C. This is the same 12-bit identity described in the V3.2-A architecture. `canonicalPitchSet` and `canonicalPitchSetId` from `core/pentatonic/pitch.ts` remain the string identity (`"0,2,4,7,9"`).

| View | Count | Empty set (0) | Chromatic set (4095) | Single C (1) |
| --- | --- | --- | --- | --- |
| All pitch-class sets | 4,096 | included | included | included |
| Tonic-fixed collections | 2,048 | excluded | included | included |

Tonic-fixed means bit 0 is set. It is not a list of musical scales.

Each mask is one row. Registrations that share a mask are listed on that row. `hex_major_omit_fourth` and `maj9` stay two names on one set.

`classifyPitchClassSet` runs only when the set has 6 pitch classes. A 5-note set has no Forte label. The Forte string is a class label, not a scale name. Explorer-only classes keep `EXPLORER — NOT MUSICALLY APPROVED`. Unregistered masks, including the empty set and the chromatic set, are `MATHEMATICAL SET`.

Spelling uses `PENTATONIC_NOTE_CHOICES`. Intervals from C are the pitch-class numbers themselves.

Pentatonic registrations link to `#/pentatonic`. Hexatonic registrations link to `#/hexatonic`. Those buttons open the existing page. They do not load the selected id into that page.

## Filters

- Pitch-class cardinality 0–12.
- All sets or tonic-fixed.
- Family strings already stored on the joined rows (`anhemitonic`, `diatonic_pentatonic`, `scalar`, `wps-resolution-tension`, `provisional`, `advanced`, and the other colour families).
- Status: `verified`, `catalogue`, provisional, advanced, explorer, `MATHEMATICAL SET`.
- Search by note names or a list of pitch classes, by mask number, by Forte id, or by a registered id or display name.

The list pages 64 rows at a time. Page count for the unfiltered power set is 64.

`catalogue` and `verified` match a registration on that exact mask. They do not rename every transposition in a Forte class. `EXPLORER — NOT MUSICALLY APPROVED` matches an unregistered six-note set whose class status is explorer.

## Fretboard preview

`FretboardPanel` is mounted read-only. Open strings are the existing standard-tuning MIDI pitches `GUITAR_OPEN_STRING_MIDIS` (`E2 A2 D3 G3 B3 E4`). Frets 0–12. Every fret whose pitch class is in the selected set gets a dot.

The panel’s note type requires a vault role. Every dot uses `primaryTension` so the existing swatch can draw. The page states that this colour is a marker, not a scale degree, a CAGED shape, or a fingering. `pcFretboard` is not called. Alternate tunings are not offered. `positionLock` keeps the window from cropping.
