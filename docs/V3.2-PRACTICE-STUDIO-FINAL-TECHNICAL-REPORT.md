## Practice playback and files

Generated exercises play through the existing Tone.js Transport. Repeat, loop, and the metronome use that same Transport. The metronome is not written into the MusicXML.

`barQuarters` is `beats × 4 / beat-type`. A 6/8 bar is 3 quarters and 6 eighth-note clicks. Tests check bar length, pitch-class membership, tempo, repeat offset, click spacing, save/reopen, and a rejected hash.

`practice-session` version 1 stores MusicXML and its SHA-256. Reopen does not regenerate. A changed score is rejected. The file does not store a WWH or Sibelius path.

Open File and Open in Finder call the existing desktop bridge. This session did not launch the desktop app. Those two buttons were not clicked in Electron.

## Integration

Generate, BHL, Hexatonic, and Pentatonic each write one copied handoff. A bad source, a file path, a mask that disagrees with the registration, or a status that disagrees with the registration is rejected.

A collection mask is the registered set transposed by the reference pitch class. Provisional and advanced strings are copied from the registration.

The practice page restores the handoff on mount. Saving or exporting that score writes a new practice file. The source file is not opened for writing.

## Limitations

- Tonal named 85 scales, not the research estimate of about 92.
- Forte Z text and the empty-set number differ from music21 8.3’s own strings, as documented above. The prime and A/B flag matched.
- Generate custom open-string text is not a practice tuning id. An unknown id falls back to standard and the fretboard states that limit.
- The pentatonic practice button sends the colour, centre, and seed. That panel has no tuning control, so the studio tuning stays standard unless the handoff includes one.
- Generate sends the score, seed, and tuning preset. It does not infer one pitch-class set from a multi-chord score.
- Audio scheduling was checked as times. The sound was not heard.
- Open File and Open in Finder were not exercised in a running desktop app.
- No artistic approval is claimed.
