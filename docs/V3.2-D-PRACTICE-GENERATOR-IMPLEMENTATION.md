## What the page does

`#/practice` still lists the Scale Explorer and the fretboard. The Practice Generator reads the selected mask, the root, the resolved tuning, and the position filter.

Generate builds one exercise. Generate another keeps the current controls and advances the seed by 1. The result panel shows the title, family, pitch sequence, rhythm and metre, scale identity and status, seed, guitar notes, and validation errors.

Playback, save, and MusicXML export stay off this page. Practice Session stays unavailable.

## Exercise families

| Family | When it runs | Engine |
| --- | --- | --- |
| Scale pathways | Any non-empty set | Ordered pitch classes from the explorer transposition. Rhythm slots pass through `sourceRhythmAfterTransform`. Beginner: ascending or descending. Intermediate adds alternating. Advanced adds intervallic (every second degree). |
| Melodic cells | 3 notes at Beginner, 4 at Intermediate, 5 at Advanced, and only when the set is at least that size | `transformCell` (`original`, `rotation`, `transposition`, `M-DEG`, `M-NEAR`). A transform that leaves the set or `guitarRange()` is skipped. |
| Pentatonic studies | A `pentatonic-colour` registration, one of the 20 colours | `generatePracticeExample` with `SPARSE` / `INTERMEDIATE` / `EXPANDED`. The cell is tiled with `transformCell` rotation. |
| Triad and dyad studies | A Tonality Vault melodic triad whose pitch classes sit inside the sounding set | `selectQuadratonicMelodySpec`, then `buildGuitarGripLibrary`. Beginner uses dyads. Intermediate uses triads. Advanced uses both. Four-note vault grips are omitted. |
| BHL colour studies | An established `hexatonic-scalar` or `hexatonic-wps` registration whose resolved pitch classes match the sounding set | `resolveBhlHexatonicColour` and `applyHexatonicStrategy` (`dialogue`, `liquid`, `sparse`). Provisional, advanced, Explorer, and mathematical rows are refused. |
| Rhythmic studies | Any non-empty set | `planPhraseOnsets` with `state-onsets`, `displace`, `augment`, `diminish`, `ostinato`, `silence-window`, or `metre-compress`. The bass grid is a planner input. It is not a score and it is not saved. |

Difficulty labels on the page are Beginner, Intermediate, and Advanced. They map to the existing practice grades `SPARSE`, `INTERMEDIATE`, and `EXPANDED`.

Bar counts are 4, 8, and 16. Metres are `4/4`, `3/4`, `2/4`, `5/4`, `6/8`, `7/8`, `9/8`, and `12/8`, the metres `beatUnitQuarters` already describes. Tempo is stored from 40 to 240. Nothing plays it.

A standard-tuning position filters pathway and cell MIDI to frets in `practicePositionWindow`. Alternate tunings do not apply that window and do not call `pcFretboard`. Grip frets on an alternate tuning come from `buildGuitarGripLibrary` for that tuning id.

## Guitar notes

Every sounding pitch is checked with `inGuitarRange()`. Nearest in-range MIDI is chosen so a closer octave is preferred. The result says this is a pitch sequence, not a fingering. A library grip is not described as physically playtested. `positionShiftWarnings` runs only on standard tuning, and a clear report is not a playability approval. No TAB is written. No CAGED pattern is stored.

## What stays untouched

The generator copies pitch classes out of the explorer row. It does not write the registration, the status string, a WWH score, a BHL project, or a pentatonic project. Provisional and advanced statuses stay on the row. They are not relabelled as Core.

`generateHexatonicPhrase` is not called. That writer always emits its own six-bar phrase. Colour studies use `applyHexatonicStrategy` on a new event list so the requested bar count can be kept. `runGoldenPath`, Song Mode C1–C7, and the string-quartet rhythm engines are not called.

## Limitations

- No metronome, session file, MusicXML, notation preview, or audition. Those are V3.2-E.
- A pitch inside the set and inside `guitarRange()` is not a verified fingering.
- `generateHexatonicPhrase` is not the colour-study writer, because its bar count is fixed.
- A triad/dyad study runs only when a vault melodic triad is a subset of the selected set.
- A 5-note cell is refused when the set has fewer than 5 pitch classes. A shorter cell is not substituted.
- Position filtering can make a pathway unavailable when no in-range MIDI for a pitch class sits in that fret window.
- Tempo is stored on the exercise and is not heard.
